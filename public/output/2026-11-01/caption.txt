[2026-11-01] 오늘 볼 만한 AI·테크 뉴스 TOP 3

1. Claude Code 확장에 백도어
무슨 일? Cursor 확장 마켓에서 변조된 Claude Code 버전이 약 11시간 유통됐다. SSH 백도어를 시도했으며 최대 5,000명이 영향 가능 대상이다.
왜 중요? 코딩 AI의 확장 공급망이 개발 PC 침입 경로가 될 수 있다.
다음엔? 해당 버전 설치 여부 확인, 침해 지표 점검과 인증정보 교체.

2. PR 초안 10개 중 4개는 AI
무슨 일? GitHub 9월 PR의 40% 이상을 에이전트가 시작했다. 3월엔 17%였고, 9월에만 약 1억1,000만 건이었다.
왜 중요? 코딩 에이전트가 실험 도구에서 개발 협업의 기본 구성원으로 이동 중이다.
다음엔? 코드 품질·리뷰 부담·CI 비용이 실제로 개선되는지 검증.

3. OLED 방식으로 양자칩 만든다?
무슨 일? NVision이 AI로 분자 후보를 좁히고 약 40종을 합성했다. 유기 분자를 칩에 얇게 입히는 양자 하드웨어 연구를 Nature에 발표했다.
왜 중요? 기존 디스플레이·반도체 공정을 양자칩 제조에 활용할 가능성이 있다.
다음엔? 실제 칩의 큐비트 성능·오류율과 제조 수율을 검증.

오늘 한 줄: 코딩 AI가 개발을 주도하자 보안은 흔들리고, 양자칩 제조법은 바뀐다.
